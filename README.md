# homebrew-shadenet

Homebrew tap for [ShadeNet](https://github.com/dmarzzz/shade-tree-node), proof-gated Tor egress for agents.

```sh
brew tap dmarzzz/shadenet
brew install shadenet
```

The formula under `Formula/` is written by the release workflow of dmarzzz/shade-tree-node on every final release (prereleases leave it alone).
